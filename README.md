# Fading Athens

Website for **Fading Athens**, a photo project by Steven A.J. Beijer, photographer and urban archaeologist: chipped paint and fading facades, elaborate doorways and darkened arcades — a salute to an Athens fondly remembered yet rapidly fading.

Live at https://fadingathens.com · Instagram [@fadingathens](https://www.instagram.com/fadingathens/)

This is a static site: `index.html` plus the `img/` folder. It is served by GitHub Pages from the `main` branch.

Photographs © Steven A.J. Beijer. Illustrations and postcards in collaboration with Xany Mendez.
